# Phase J5 — Qualité & observabilité

## Objectif de phase

Industrialiser l'exploitation avec des garde-fous mesurables et une gouvernance de preuve.

## Chantiers prioritaires

- Définir SLI/SLO minimum : disponibilité API, latence P95, taux d'erreurs, temps de recovery.
- Établir un release gate : smoke API, non-régression frontend, diagnostics DB clés.
- Mettre en place l'observabilité minimale : logs standardisés, dashboard santé, vue incidents.
- Formaliser l'escalade : rôles, seuils, actions, délais.

## Définition de terminé (DoD)

- [ ] Preuve versionnée (log/JSON/rapport)
- [ ] Documentation de référence mise à jour
- [ ] Risque principal + mitigation tracés
- [ ] Commit explicite et traçable
