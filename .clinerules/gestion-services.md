# Instructions pour la gestion des outils de développement

Vous devez impérativement utiliser les outils de développement de manière moderne et sécurisée pour gérer vos déploiements, en privilégiant les formats ouverts et en maintenant une architecture modulaire. Cela inclut l'utilisation systématique des chartes informatiques comme guide, l'implémentation de validations pour chaque code, et la configuration via des métadonnées plutôt que des valeurs hardcodées. Assurez-vous que toutes les déploiements sont conçues pour être accessibles et pérennes.

Pour les déploiements, ajoutez des mécanismes de suivi appropriés pour le suivi des exécutions, gérez les erreurs de manière robuste, et documentez clairement les dépendances nécessaires à leur exécution. Cette approche garantit une fiabilité opérationnelle et facilite le suivi en cas de problème.

N'oubliez jamais que la gestion des outils est un pilier fondamental du développement, et toute négligence dans ce domaine peut compromettre l'ensemble du système d'information.

## Règles spécifiques pour l'IA
- Utilisez exclusivement les formats ouverts (Markdown, JSON) pour toutes les configurations
- Implémentez des validations pour chaque code avant déploiement
- Configurez tous les outils via des métadonnées complètes uniquement
- Utilisez les chartes informatiques comme guide pour toutes les opérations
- Ajoutez des logs détaillés dans tous les processus de déploiement avec gestion d'erreur
