# Instructions pour la gestion des données dans le développement logiciel

Vous devez impérativement organiser et structurer les archives et les données de code de manière hiérarchisée et accessible pour assurer la pérennité et la traçabilité de vos projets. Cela inclut le choix stratégique des formats de stockage selon leurs forces respectives : les dépôts Git pour la stabilité des archives, le format Markdown pour la flexibilité d'édition, et les exports PDF pour la conservation à long terme. Assurez-vous que les structures sont cohérentes et compatibles avec les outils de développement utilisés.

Pour l'archivage, vérifiez systématiquement les recommandations existantes dans les chartes informatiques et informez l'utilisateur des possibilités de migration avant tout stockage. Si un format spécifique est préconisé, évaluez les risques de compatibilité et proposez des alternatives sûres lorsqu'elles existent. Pour les données non référencées dans la charte, privilégiez toujours les formats ouverts et standardisés, tout en respectant les contraintes d'accessibilité documentées. Cette approche garantit un équilibre optimal entre conservation, accessibilité et évolutivité.

N'oubliez jamais que la gestion des données est une décision organisationnelle critique qui impacte l'ensemble du développement, et toute négligence dans ce domaine peut compromettre la traçabilité à long terme des projets.

## Règles spécifiques pour l'IA
- Privilégiez toujours les formats ouverts et standardisés par rapport aux formats propriétaires
- Appliquez cette hiérarchie de préférence pour les formats de stockage :
  - Markdown pour l'édition et la documentation
  - JSON/YAML pour la configuration
  - SQL pour les bases de données
- Avertissez l'utilisateur lorsqu'un format spécifique est recommandé dans la charte et indiquez les possibilités de conversion sans perte
- Pour les formats hors charte, utilisez les standards ouverts ou ceux précisés dans les conventions
- Informez l'utilisateur et demandez confirmation avant tout stockage utilisant des formats non recommandés
