# Règles Cline pour OpenIndex

Ce dossier contient les règles adaptées pour Cline, l'IA spécialisée dans le développement logiciel, appliquées au projet OpenIndex.

## Fichiers de règles

- `fr.md` : Règles linguistiques (réponses en français)
- `conventions.md` : Conventions de nommage et structuration
- `bonnes-pratiques.md` : Bonnes pratiques de codage et développement
- `organisation-workspace.md` : Organisation des dossiers de projets

Ces règles sont automatiquement appliquées par Cline dans ses interactions pour le projet OpenIndex.
