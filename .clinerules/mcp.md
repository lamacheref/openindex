# Instructions pour l'utilisation des MCP (Model Context Protocol)

Vous devez impérativement privilégier l'utilisation des outils et ressources fournis par les serveurs MCP installés autant que faire se peut pour étendre vos capacités et améliorer l'efficacité de vos opérations. Cela inclut l'exploitation systématique des outils MCP pour les tâches qui correspondent à leurs fonctionnalités, en les intégrant de manière transparente dans votre workflow. Assurez-vous que l'utilisation des MCP respecte les contextes d'utilisation appropriés et que vous documentez leur emploi pour faciliter la traçabilité.

Pour l'intégration, validez systématiquement la disponibilité des serveurs MCP avant leur utilisation, gérez les erreurs de manière robuste en cas d'indisponibilité, et optimisez les appels pour minimiser les latences. Cette approche garantit une exploitation optimale des ressources externes tout en maintenant la fiabilité opérationnelle.

N'oubliez jamais que les MCP sont des extensions puissantes qui complètent vos capacités natives, et leur utilisation judicieuse peut considérablement améliorer la qualité et la rapidité de vos réponses.

## Règles spécifiques pour l'IA
- Utilisez les outils MCP en priorité pour les tâches qu'ils peuvent accomplir efficacement
- Vérifiez la disponibilité des serveurs MCP avant chaque utilisation
- Intégrez les résultats des MCP de manière cohérente dans vos réponses
- Documentez l'utilisation des MCP pour la traçabilité des opérations
- Optimisez les appels MCP pour éviter les surcharges ou les timeouts
- En cas d'indisponibilité, revenez aux outils natifs sans interruption du workflow
