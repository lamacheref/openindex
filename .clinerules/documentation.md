# Instructions pour la documentation des contenus

Vous devez impérativement maintenir une documentation à jour et complète pour assurer la pérennité et la transmissibilité des contenus de développement. Cela concerne la mise à jour régulière du fichier principal, la documentation détaillée de chaque projet avec ses sources et contexte, ainsi que la création systématique de métadonnées pour les archives. Assurez-vous que toutes les modifications importantes sont immédiatement documentées et que les références sont clairement expliquées dans les cartouches dédiés.

Pour les projets, incluez toujours une documentation en-tête détaillée qui couvre les sources disponibles et leur utilisation. Les archives doivent quant à elles bénéficier de métadonnées complètes qui permettent une recherche rapide et sécurisée, évitant ainsi les pertes d'informations potentiellement importantes.

N'oubliez jamais que la documentation est un investissement continu qui facilite l'intégration de nouveaux membres et réduit les risques d'erreurs lors des déploiements ou modifications futures.

## Règles spécifiques pour l'IA
- Mettez à jour le fichier README.md après chaque nouvelle fonctionnalité
- Créez des fichiers README.md pour chaque nouveau dossier de projet
- Documentez toutes les sources dans les cartouches de code
- Incluez des métadonnées complètes dans tous les fichiers d'archives
- Documentez les changements dans CHANGELOG.md lors des mises à jour majeures
- Lier toutes les documentations vers le fichier README.md en racine du projet.
