## Priorité 1 — Fonctionnalités avancées T-INDEX-01

- [ ] **Scrutation périodique** : Scheduler configurable (exécution 22h-6h)
  - Utiliser `croniter` (déjà en dépendance) pour parser les expressions cron
  - Ajouter une table `indexer_schedules` ou réutiliser le mécanisme d'`archive_scheduler.py`
  - Handler : créer automatiquement les jobs aux heures planifiées
- [ ] **Multi-espaces SMB** : Permettre au worker de traiter plusieurs sources
  - Actuellement le worker traite un job à la fois → suffisant pour une file FIFO
  - Ajouter la possibilité de prioriser les espaces (ordre de création)
  - Ajouter des métriques par espace
- [ ] **Files différenciées** : Queue rapide (<200Mo) vs queue lente (≥200Mo)
  - Modifier la logique de polling du worker pour intercaler les petits fichiers
  - Ou créer deux workers distincts (rapide + lent)
  - Ajouter le champ `queue_type` dans `indexer_jobs`
- [ ] **Hashage xxHash** : Remplacer SHA256 par xxHash pour les performances
  - Ajouter la bibliothèque `xxhash` aux dépendances
  - Modifier le calcul de hash dans le crawl (get_file_info)
  - Ajouter une migration pour recalculer les hashs existants si nécessaire
- [ ] **Détection des changements** : Mode incrémentiel (hash + timestamps)
  - Avant d'insérer un fichier, vérifier s'il existe déjà en base
  - Si hash identique et timestamp inchangé → ignorer (pas de modification)
  - Si hash différent → mettre à jour le fichier
  - Si fichier présent en base mais plus sur le disque → marquer comme supprimé
- [ ] **Gestion des ordures** : Détection automatique des fichiers indésirables
  - Patterns à détecter : *.tmp, ~*, Thumbs.db, .DS_Store, *.bak, *.swp
  - Option 1 : ne pas indexer ces fichiers (filtrage en amont)
  - Option 2 : les indexer avec un flag `is_garbage = true`
  - Configuration des patterns via la table `artefact_filters` (déjà existante)
- [ ] **Base PostgreSQL optimisée** : Créer les tables smb_spaces, directories, files
  - Actuellement le worker insère via `insert_file()` qui utilise la structure existante
  - Vérifier que le schéma correspond aux besoins PROJET.md (avec hash_xxhash)
  - Ajouter les index pertinents (sur hash, path, space_id)
